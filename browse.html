What is a Regular Expression?

A regular expression is a symbolic pattern used to describe sets of strings. It can match sequences, alternation, repetition, and optional groups.

  • Concatenation: ab means "a" followed by "b".
  • Alternation: a|b means either "a" or "b".
  • Kleene Star: a* means zero or more repetitions of "a".

What is an ε-NFA?

An ε-NFA is a nondeterministic finite automaton that allows transitions on the empty string ε. This makes it easier to represent regex operations like optional groups and alternation.

Conversion Rules

The conversion process builds small ε-NFA fragments for regex atoms and combines them with epsilon transitions for operators like concatenation, alternation, and Kleene star.

Step-by-Step Example

For regex (a|b)*abb, the converter creates a start state, repeated alternations for (a|b)*, and chain transitions for the ending pattern abb.
